ABOUT THE CLUB

AI醒觉社。
AI Awareness Club.

一个围绕 AI 能力、认知成长和价值共创持续建设的学习共同体。

为什么存在

AI 技术变化很快。工具会变，工作方式会变，人的问题却需要在现实中解决。我们希望把公开知识沉淀为可以执行和检验的行动指南，帮助更多人更高效地工作、建立判断并找到共创机会。

这里的基础框架是「术、道、圈」：用工具解决问题，用复盘修正方向，用有边界的合作扩大价值。它是一套行动组织方式，不是可以保证个人收益的科学公式。

谁在建设

项目关联品牌为 AI酋长Andy，由 AIPMAndy GitHub 账号维护公开开源材料。品牌、社群和权益介绍的权威更新入口为 官方社群页。

公开与非公开

本仓库开放经授权的文字、操作模板及网站代码。付费知识库、内部会员交流、个人申请信息与客户隐私均不在公开范围。引用开源内容时，请遵守对应内容许可，并核实信息的适用范围和更新时间。
