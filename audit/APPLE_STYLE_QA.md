# Apple 风格重设计 · 对抗式验收

日期：2026-10-29
目标：将 AI 醒觉社开源知识站从深绿色企业介绍页转为以阅读、探索和实践为核心的高品质产品型网站。

## 变更范围

- 全站统一字体层级、辅助色、Apple 风格的留白、胶囊按钮和圆角内容卡片。
- 首页：品牌主标题、简洁副标题、原创蓝紫光学球体插画、两个清晰行动入口。
- 术 / 道 / 圈：深色三层内容展示；现有学习路线选择交互保持不变。
- 内页：学习路线、知识列表、FAQ、社群介绍与 9 篇可勾选指南适配统一视觉。
- 品牌开源封面与网站统一，不使用苹果标识、产品照片或受限字体文件。
- 新增 `DESIGN.md` 维护设计令牌、组件规范与修改边界。

## 反向检验与修复

| 质疑 | 处理 | 验收 |
| --- | --- | --- |
| 只有首页漂亮、内页残留旧样式？ | 对功能页和指南页使用统一样式覆盖，逐页截屏 | 3 类内页手机端检查 |
| 手机端能否用？ | 重新设计响应式主视觉、双列选择器和单列卡片 | 390px 无横向溢出 |
| 网页是否只是图片？ | 保留语义 HTML、导航、可见正文与可操作链接 | 所有 14 页源码与结构数据测试通过 |
| 会不会侵犯 Apple 素材和字体？ | 原创 SVG、系统字体、仅参考通用交互与层级设计 | 资源可在 `site/assets/` 检查 |
| 交互会不会因换皮失效？ | 保留原 app.js 与功能选择器 | 选择器、搜索、菜单、进度、下载测试通过 |
| 是否破坏 GEO？ | 生成器不修改 canonical、JSON-LD、sitemap 或 llms.txt 内容来源 | 自动测试对 SEO 和内链校验通过 |
| 动画会不会让人不适？ | 仅一处轻微 transform 动画并遵守 reduced-motion | CSS 中可检验 |
| 旧 GitHub 封面会不会冲突？ | 同步生成新的清爽版 README 横幅 | `site/assets/readme-hero.svg` |

## 已执行验证

- `python3 scripts/build.py`：14 个页面构建成功。
- `python3 -m unittest discover -s tests -v`：9 项通过。
- `node --check site/assets/app.js`：通过。
- Chromium 在 1440×900 / 820×1180 / 390×844 渲染首页，3 种宽度均 `scrollWidth <= innerWidth`。
- Chromium 手机端渲染知识库、初学者指南、社群介绍，均无横向溢出。
- 浏览器测试：选择求职学习路线、移动端展开/收起菜单、搜索 Agent、无结果提示、完成打卡、导出 TXT，通过。
- 浏览器控制台：无运行时脚本异常。

## 诚实边界

由于此执行环境限制浏览器直接访问 `localhost` 和 `file://`，视觉检查采用 Chromium 的 HTML `set_content`，并内联项目中实际生成的 CSS/JS/SVG。此方式验证排版及前端交互，但不能替代部署后的真实 HTTP 请求、安全头、缓存、CDN 和线上资源路径测试。仓库已有的 GitHub Pages 流程继续承担构建及线上冒烟检查。
