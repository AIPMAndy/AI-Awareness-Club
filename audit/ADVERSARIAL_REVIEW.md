# AI醒觉社 · 对抗式审核记录

审核初稿：2026-10-29。此文件记录真实完成的本地检查与明确未完成的外部发布事项。它不构成「零缺陷」或「已获得搜索排名」的证明。

## 本项目的验收原则

1. **内容价值：** 不接受只有营销口号的知识库。每条指南必须有操作、交付物、常见错误和 FAQ。
2. **证据边界：** 不编造 Offer、客户、收入、粉丝数或搜索排名；会员条款引用官网并以更新页面为准。
3. **前后端一致：** 不在多处复制不同版本的教程，统一由 `data/guides.json` 生成 9 篇独立 HTML。
4. **真实可用：** 关键按钮需要完成动作，用户可不登录就操作和导出进度。
5. **搜索可信：** Schema 必须与页面可见内容一致；GEO 不能冒充搜索平台保证机制。
6. **隐私安全：** 不上传交互状态，不公开社群会员和客户敏感信息。

## 第一轮：逻辑与发布风险

| 对抗问题 | 发现 | 修复或结论 |
|---|---|---|
| 名称会不会混淆？ | 用户曾考虑其他英文名 | 所有公开内容统一 `AI醒觉社 / AI Awareness Club`；脚本测试禁止混用 `AI Awake Group` |
| 免费是否变相提供会员付费资源？ | 易使开源与付费权益混淆 | README、FAQ、About 明确：只公开授权原创资料；会员政策以官网为准 |
| 有否伪造结果或收益承诺？ | 求职、MBTI、副业、GEO 均易夸大 | 只给可执行的方法与证据表；没有个人案例金额、保证排名或就业承诺 |
| 先有 GitHub 还是先说上线？ | 当前 GitHub 连接缺少「新建仓库」能力 | 不宣称仓库已创建；提供完整源码、RELEASE.md 和实际发布步骤 |

## 第二轮：技术与信息架构

| 对抗问题 | 检查或修复 |
|---|---|
| 只有首页，AI 无法检索独立问题？ | 采用 14 个独立 HTML 页面，全部有唯一标题、description、canonical、内部链接和 JSON-LD |
| 生成器可能把正文与结构化数据弄成两个版本？ | 都从同一 JSON 事实源生成，测试 JSON-LD 可以反序列化且 FAQ 与可见内容一致 |
| 未部署时直接打开 HTML 会坏吗？ | 发现绝对资源路径问题，已修复为相对导航和资源链接；canonical 仍保持目标线上地址 |
| 浏览器本地敏感信息会被发送？ | 没有任何页面程序化 API 请求、分析追踪或第三方字体加载；状态仅本地浏览器保存 |
| 内链有没有坏？ | `unittest` 检查全部 14 页内部链接指向存在的文件 |
| SEO 文件是否自动同步？ | `sitemap.xml` 与 `llms.txt` 从 14 个页面 / 9 篇指南构建；`unittest` 对齐 URL 列表 |
| 生成结果是否可复现？ | 同一数据构建出同样的 `docs`；CI 增加 `git diff --exit-code -- docs` |

## 第三轮：浏览器交互和视觉

使用 Chromium 的隔离页面渲染，分别模拟 1440 × 900 桌面、820 × 1024 平板和 390 × 844 手机，检查页面布局与用户交互。

- 3 种尺寸的首页均正常渲染，**无水平溢出**。
- 路径切换正确改变标题及目标指南 URL。
- 移动端菜单可以展开；深浅色切换正常。
- 搜索 `Agent` 后从 9 条过滤为 1 条，选择「认知成长」后也只显示相应 1 条。
- 指南步骤勾选，进度由 `0/7` 变为 `1/7`；TXT 导出触发浏览器下载；确认后可重置进度。
- 检查脚本运行错误：**0**（修复浏览器测试工具的内联脚本嵌入问题后）。
- 辅助文字在浅色模式的颜色对比度约为 4.0:1，低于普通文字推荐的 4.5:1；**已调深**，并复测。

**测试限制：** 本环境浏览器限制直接访问本地 HTTP/file URL，所以采用 `set_content` + 内联本站静态 CSS/JS 渲染及交互检查，不等同于完整线上网络验收。尤其 GitHub Pages HTTP 状态、真实外链可达性、跨刷新本地存储持久性、Search Console 收录均须上线后测试。

## 下一轮应该拒绝什么？

- 任何号称「提交一次 llms.txt，所有大模型自动收录」的建议。
- 没有第一手证据的成功案例、匿名虚构评论和不加限定的营销承诺。
- 为凑关键词批量生成无原创价值的页面。
- 为提升转化而隐藏免费与付费社群之间的区别。
- 未经授权直接复制收费知识库或会员交流内容。

**总体结论：** 本地开源项目源代码、内容源、静态网页与自动化测试已生成并通过检查；发布到新的 GitHub 仓库及外部搜索平台验证尚未执行。审核等级：本地可交付候选版；线上待验收。
